# FAIR statement

## Findable

- descriptive repository title and keywords;
- `CITATION.cff`;
- machine-readable `review-manifest.json`;
- stable release target `v0.1.0`;
- DOI and PMID identifiers where available.

## Accessible

- public GitHub repository is the intended canonical source;
- review text is Markdown/MyST;
- evidence artifacts are JSONL and CSV;
- source access status is recorded in the evidence table.

## Interoperable

- ORAtlas review manifest schema `1.0.0`;
- controlled relation types and TRUST criteria;
- BibTeX bibliography;
- UTF-8, repository-relative paths, no executable source ingestion required.

## Reusable

- CC BY 4.0 for original review text and structured mappings;
- explicit provenance and AI disclosure;
- every relation remains agent-proposed until human review;
- limitations and directness are preserved at source and relation level.
